# RandomTP

RandomTP is a simple random teleport plugin for PowerNukkitX.

Players can use `/rtp` to teleport to a random and safe location in the world.

## Installation

1. Download `RandomTP.jar`.
2. Place the file in your server's `plugins` folder.
3. Restart your server.

## Usage

Use this command in the game:

```
/rtp
```

The player will be teleported to a random location.

## Configuration

After the first server start, open:

```
plugins/RandomTP/config.yml
```

Here you can change:

- The worlds where RandomTP can be used
- The minimum and maximum teleport distance
- The cooldown between teleports

Restart the server after changing the configuration.

## Languages

RandomTP automatically uses the language selected by the player.

The following languages are included:

- English
- Chinese (Simplified)
- French
- German
- Italian
- Japanese
- Korean
- Portuguese (Brazil)
- Russian
- Spanish
- Turkish
